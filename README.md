# ItsMe — The Voice of Me

ItsMe is a personal voice AI training pipeline for turning your own recorded speech into a natural, reusable TTS voice model.

Target base model: `Fun-CosyVoice3-0.5B-2512`.

## End-to-end pipeline

```text
raw recordings
  -> audio validation / segmentation
  -> Whisper transcription
  -> transcript review
  -> CosyVoice dataset preparation
  -> speaker embeddings
  -> speech tokens
  -> parquet dataset
  -> CosyVoice 3 fine-tuning
  -> checkpoint evaluation
  -> inference / streaming API
```

The training data layout follows the official CosyVoice 3 recipe: `wav.scp`, `text`, `utt2spk`, `spk2utt`, speaker embeddings, speech tokens, and parquet data. Keep the upstream CosyVoice repository pinned/updated separately rather than copying its model internals into ItsMe.

## Requirements

- NVIDIA CUDA GPU is recommended for training.
- Python 3.10 / Conda.
- Your own voice recordings or recordings for which you have explicit authorization.
- 24 kHz WAV training audio.
- Git with submodule support.

A Mac Mini M4 can be used for dataset preparation and inference experiments, but serious CosyVoice training should run on an NVIDIA CUDA machine.

## 1. Clone

```bash
git clone https://github.com/the-shoaib2/itsme.git
cd itsme
```

## 2. Install

```bash
make setup
```

Or manually:

```bash
conda create -n itsme python=3.10 -y
conda activate itsme
bash scripts/install.sh
```

## 3. Download the base model

```bash
python scripts/download_model.py
```

This downloads `FunAudioLLM/Fun-CosyVoice3-0.5B-2512` into `models/Fun-CosyVoice3-0.5B`.

## 4. Add your raw voice recordings

```text
data/raw/
  recording-01.wav
  recording-02.wav
  ...
```

Use clean recordings with one speaker, minimal background noise, consistent microphone placement, and varied natural speech.

## 5. Build the dataset

Run:

```bash
make prepare
```

Or step by step:

```bash
python scripts/prepare_audio.py --input data/raw --output data/processed
python scripts/transcribe.py --input data/processed/wavs --output data/transcripts/transcripts.jsonl
```

Review and correct `data/transcripts/transcripts.jsonl` before training. Then:

```bash
python scripts/prepare_cosyvoice.py \
  --audio-dir data/processed/wavs \
  --transcripts data/transcripts/transcripts.jsonl \
  --output data/cosyvoice/my_voice \
  --speaker itsme
```

Then extract speaker embeddings and speech tokens and build parquet data:

```bash
bash scripts/extract_features.sh
```

## 6. Fine-tune

Single GPU:

```bash
export CUDA_VISIBLE_DEVICES=0
bash scripts/train.sh
```

Multi-GPU:

```bash
CUDA_VISIBLE_DEVICES=0,1,2,3 bash scripts/train.sh
```

The training wrapper should call the upstream CosyVoice training entry point and expose configuration through `configs/`, rather than hard-coding model paths or hyperparameters in Python.

## 7. Evaluate checkpoints

```bash
python scripts/evaluate.py \
  --checkpoint runs/cosyvoice3/llm/latest.pt \
  --sentences evaluation/sentences.txt \
  --output evaluation/generated
```

Keep validation/test utterances separate from training. Compare checkpoints for speaker similarity, pronunciation, naturalness, prosody, repetition, and long-form stability.

## 8. Inference

```bash
python scripts/infer.py \
  --model models/Fun-CosyVoice3-0.5B \
  --prompt data/processed/wavs/reference.wav \
  --text "Hello. This is my voice generated by ItsMe." \
  --output outputs/demo.wav
```

## Dataset layout

```text
data/
├── raw/                    # original recordings; never modify these
├── processed/wavs/         # normalized, segmented 24 kHz WAV files
├── transcripts/            # Whisper output + human corrections
└── cosyvoice/my_voice/
    ├── wav.scp
    ├── text
    ├── utt2spk
    ├── spk2utt
    ├── utt2embedding.pt
    ├── spk2embedding.pt
    ├── utt2speech_token.pt
    └── parquet/
```

## Data quality

Do not train on clips with overlapping speakers, music, clipping, severe reverberation, or incorrect transcripts. Keep raw recordings immutable. Split train/validation/test before training so evaluation remains meaningful.

## Safety

ItsMe is intended for voices you own or are authorized to reproduce. Do not use it to impersonate another person without permission.
